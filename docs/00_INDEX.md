## 4. 维护约定

* **编号只增不改**：`NN_TOPIC.md`，两位数字前缀；跨文档引用写「`docs/48 §3.2`」。
* **每篇开头写三行头**：状态（✅/⏳/✗）、工具、产物（`out_*.json` 等）——新文档照抄这个格式。
* **结论与证据分家**：规格书放结论 + 指针，原始反汇编 / 带行号证据放 `annex/` 或该篇的「证据」节。
* **伪码陷阱**（形参逆序 + 吞 `break`）见 48 §0；冲突时以字节码 / 原生为准。
* 旧的逐轮过程记录**不要再往规格书里追加**：过程写进 `_archive/`，规格书只保留结论。
