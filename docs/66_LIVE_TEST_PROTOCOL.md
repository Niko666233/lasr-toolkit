# 66 — 实机验证协议（需要你在自己机器上开一次游戏的那部分）

这条线到目前为止的判据全部来自**静态/沙箱**证据：语料字节码、反汇编、真 VM 的沙箱执行。
但有**一桶**东西沙箱里拿不到，只能从真实跑的引擎里读 —— 这份文档就是那一桶，以及你需要做的最小动作。

## 一、为什么这一桶必须实机

沙箱里我们能让真 VM 跑语料的 `<clinit>` / 指定方法（`uni_dump.py` + 探针类），但：

| 桶 | 沙箱里的现象 | 根因 |
|---|---|---|
| gui 控件工厂默认值 `kind 6/13/37/56` | 真 VM 侧 `UC_ERR_READ_UNMAPPED`（传真空 `String[]` 也崩） | 这些 kind 的控件在沙箱里**从没被真正构造过**，工厂读的是引擎里现成的控件表 |
| Part/Chassis 建造机真值 | 我们能记录 `configureType` 的指令流（键 + float + token）与 vis/mesh/tex 计数，但**几何/网格/纹理真值**在引擎的 C 结构里 | 模型只记指令、不造几何（docs/65 §10.25） |
| `Chassis.getSfxTable(i)` 真值 | 我们返回缓存实例（Java 侧可用），但引擎那侧是 `node + 每kind偏移表[0x7439b0][kind]` 指过去的子结构 | 我们没有 chassis 结构（docs/65 §10.29） |

## 二、你只需要做三件事（每件 ≈ 2 分钟）

对应三个**画面**，进到画面就停住，不用抓图、不用记数值、不用改任何配置：

1. **主菜单 / Loading 画面**（gui 桶）
   - 做什么：启动 `C:\Games\LASR\LASR.exe`，等主菜单出现（Loading 窗口会在启动时构造）。
   - 停在哪：主菜单界面，**别关游戏**。
2. **车辆画面**（建造机 + `getSfxTable` 桶）
   - 做什么：进到能看见一台车的画面 —— 车库/选车/任意赛道开局都行。
   - 停在哪：车在场景里（静止即可，不用开）。
3. （可选，等前两项完了再说）**任意一局的比赛中**，如果你愿意再多开一次，我可以顺带把 PACEJKA/物理侧的几处实机读数一起收掉。

进到画面后跟我说一句（中文一句就够，例如「主菜单停着了」），我这边接着做下面的部分。

## 三、我这边怎么做（你不用动手）

- 用 **REA 的调试/插桩会话**（rizin/frida，只读）附着到正在跑的那个进程，按已知偏移读对象；
  或者用项目里已有的 `tools/attach_trace.py`（我们自己的附着探针）。
- 读出来的东西直接和模型对比：控件工厂默认值逐位比、建造机的 vis/mesh/tex 计数与几何句柄比对、
  `getSfxTable(i)` 指到的子结构内容比对。
- 结果写进 `docs/65`（实机一节）+ 更新桶清单：拿到的进 ✓，拿不到的留在桶里。

## 四、安全 / 回退（你要的 fail-safe）

- **我不写你的游戏安装目录**：`C:\Games\LASR` 全程只读。我们自己的 VM 跑语料时用的是
  `UNI_FILE_REDIR` 把 `java/classes.zip` 重定向到工作区里的 scratch 副本。
- 附着是**只读**的：不 patch 指令、不改内存。如果你看到游戏卡住，直接强杀进程即可，安装目录不会变。
- 随时可以叫停：你说停，我就把这条线停在当前状态（所有产物都在工作区，没有对游戏安装的副作用）。
- 我这边不会用你的账号做任何登录/联网动作；这一桶全是本机读数。

## 五、如果某个画面你机器上进不去

告诉我具体哪一步不行（例如「没有车库菜单」「主菜单起来就崩」），我换路径：
- gui 桶可以退到「启动后任意一个能出现的窗口」，控件 kind 我按引擎的 kind 表逐个试；
- 车辆桶可以退到「回放/幽灵车」这类会自动放车的场景（docs/54 有回放格式）。
